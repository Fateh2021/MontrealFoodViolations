Comment chercher ?

  • Utilisez la recherche globale pour chercher partout en une fois.
  • Affinez avec les filtres (établissement, adresse, catégorie, statut, etc.).
  • Cliquez sur les en-têtes de colonnes pour trier les résultats.
  • Cliquez sur un établissement pour voir sa fiche complète.
  • Utilisez Exporter CSV pour télécharger les résultats filtrés.

Pourquoi ce site ?

  • Fiche établissement — historique complet par commerce.
  • Export CSV — téléchargez les résultats filtrés.
  • Statistiques d'amendes — totaux, moyennes et tendances par année.
  • Recherche avancée — filtres combinables sur tous les champs.
  • Données à jour — synchronisation automatique avec la Ville.
  • API ouverte — endpoints REST pour réutiliser les données.

Mise à jour des données

Les données sont synchronisées automatiquement environ toutes les 24 heures depuis le fichier officiel de la Ville de Montréal. Si aucun résultat n'apparaît au premier chargement, la synchronisation est peut-être encore en cours.
